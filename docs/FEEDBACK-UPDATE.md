## 如何更新

使用本次累计更新包 `paper-trail-update-with-feedback.zip`，它包含上次的归档、关键词、节点删除、迁移入口、使用说明，以及这次的反馈入口。

先导出自己的迁移包作备份。解压更新 ZIP，将里面的文件和文件夹上传到 GitHub 仓库根目录，保持路径，提交到 main。等待 Actions 部署成功后刷新原网站。无需删除仓库、重建工作流或上传 .github。

若已经上传上次更新，本次实际新增/修改的功能文件是 app/page.tsx、components/usage-guide.tsx、components/feedback-dialog.tsx；另附 scripts/smoke.mjs 和 tsconfig.json 更新检查配置，防止在项目里解压交付包时重复检查旧源码。累计包可直接覆盖同路径文件。

同一网站、同一浏览器且未清除存储时，继续使用原记录；邮箱入口不改变论文存储。
