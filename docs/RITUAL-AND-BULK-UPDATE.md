# 批量打开投稿系统与时间起卦

## 一键打开全部页面

进入「投稿系统总览」→「一键打开全部」。按钮会显示有效、去重后的链接数量；包含所有稿件，不受搜索筛选影响。完全相同的链接只开一次，HTTP/HTTPS 之外的链接不会打开。超过 10 个页面时会先确认。

浏览器通常限制一次点击打开多个页面。若被拦截，在地址栏附近的弹出窗口拦截提示中允许本站打开弹出窗口，再重试，或从未打开链接列表逐一打开。已成功打开的页面不代表已登录或核查完毕；重试全部可能再次打开先前已打开的页面。自动判断以浏览器是否提供窗口句柄为准，不能保证网络加载成功。

技术依据：[MDN window.open](https://developer.mozilla.org/en-US/docs/Web/API/Window/open)。新窗口在导航前断开 opener，设置不发送 referrer；不会自动修改本地状态。

## 投稿小仪式：传统起卦部分

工作台点击「投稿小仪式」，输入中文或英文题目 / 摘要，再点击按当前时间起卦。

采用《梅花易数》卷一「年月日时起例」的时间取数：

- 年支序数：子1，丑2，依次至亥12。
- 农历月、日按数字取数。
- 上卦：年支数 + 月数 + 日数，除8取余，余0按8。
- 下卦：上述总和加时支序数，除8取余，余0按8。
- 动爻：年月日时之和除6取余，余0按6。从下往上数爻，动爻阴阳互换得到变卦。
- 卦数对应乾1、兑2、离3、震4、巽5、坎6、艮7、坤8。

原文依据：[梅花易数卷一](https://zh.wikisource.org/zh-hans/梅花易數/卷一#年月日时起例)。界面也提供原文链接。

网站明确采用：北京时间 UTC+8、农历春节换年、民用午夜换日、23:00–00:59 为子时；闰月沿用该月序号。午夜日界、闰月处理是本工具的实现约定，不声称覆盖所有流派，不采用真太阳时。浏览器不支持农历换算时会提示错误，不编造结果。

题目 / 摘要只标记所问事项，不参与时间起卦，不分析论文质量，也不会上传或持久保存。相同农历日期、相同时辰会产生相同卦象。

## 未来一周时间：自定义趣味部分

传统时间起卦不等于有史料依据的「论文最佳投稿时间」。本工具因此将七日时段选择明确写成现代趣味映射：

间隔天数 =（上卦数 + 下卦数 + 动爻数 − 1）% 7 + 1。

六个动爻依次对应 09、11、13、15、17、09 时，生成北京时间随后七个自然日中的一个参考时段，不含起卦当天。附带的投稿准备提示是现代文案，不是古籍断语。

结果标注「传统文化体验，仅供娱乐参考，不预测审稿或录用结果」。不输出录用概率或吉凶评分，不自动改变论文、截止日期或日历。实际提交应以准备程度和真实截止日期为先。

## 更新方法

使用累计更新包 `paper-trail-update-ritual-and-bulk.zip`，包含此前全部更新。先导出个人迁移包；解压后将里面的文件和目录上传到原 GitHub 仓库根目录，保持路径并提交到 main。等待 Actions 部署成功，刷新原网址即可。无需更改 .github 或 Pages 设置。

原记录存储位置和格式不变。这次实际新增文件为 components/submission-ritual.tsx、lib/divination.ts、lib/portal-links.ts、tests/ritual.test.mjs；同时更新投稿总览、工作台、样式、使用说明和渲染检查。
