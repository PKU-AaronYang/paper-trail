# 题目分析与投稿系统总览更新

本次更新包含两个界面调整：

1. 「卜卦·投稿时间」不再只按当前时辰计算。输入的中文或英文题目/摘要会在浏览器本地经过统一大小写、Unicode 形式和空白后生成确定性的文本指纹；同时匹配少量可解释的主题词和方法词。文本指纹会参与上卦、下卦、动爻以及未来七日时段的选择，所以同一时刻更换题目会影响结果。结果中会显示匹配到的词和规则。
2. 「投稿系统总览」默认只展示正在投稿或审稿中的稿件（已投稿、编辑处理中、外审中、修回已提交）。点击「选择展示其余稿件」后才能查看准备中和已归档稿件。一键打开只作用于当前显示结果。

卜卦功能仍是传统文化体验和本地趣味算法，不预测录用、审稿速度或成功率。传统卦数的部分沿用《梅花易数》卷一的八卦数与动爻规则；题目指纹、主题词匹配和七日时间映射是本网站额外增加的现代实现，不能冒充古法或科学预测。真实投稿截止日期、期刊要求和作者准备情况优先。

## 上传到 GitHub 网页端

本次文件与此前累计更新包合并为新的 ZIP。上传时保持 ZIP 内的目录结构，从仓库根目录开始覆盖同名文件；不要删除仓库，也不要上传 `deliverables/`。`.github/workflows/main.yml` 若已存在，请保留原文件并让 GitHub Actions 自动重新部署。

浏览器中的论文记录仍保存在 `localStorage` 的 `paper-trail:data:v1`，更新网页代码不会清空记录。换浏览器或电脑前，先在「数据与备份」导出迁移包，再在新环境导入。
