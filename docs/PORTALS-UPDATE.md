# 投稿系统总览更新

工作台「我的稿件」上方新增「投稿系统总览」按钮。点击后可在一个界面浏览全部稿件，包括已归档记录，不受工作台的当前分类筛选影响。

展示标题、作者、关键词、期刊、稿号、轮次、投稿日期、本地状态和记录日期，以及完整投稿系统链接。支持搜索。

- 点击「打开投稿系统」在新标签页打开期刊网站，由用户自行登录核查。
- 未填链接的记录仍显示，可点击「补充 / 修改链接」进入编辑。
- 核查后点击「更新记录」手动保存进展。
- 总览不自动登录、读取状态或标记已核查。表格中的状态是本地记录，不是期刊系统的实时状态。

## 上传方式

`paper-trail-update-portals.zip` 为累计更新包，包含之前的归档、关键词、删除节点、使用说明、反馈邮箱和本次总览功能。算卦功能仅讨论设计，没有加入该包。

先导出个人迁移包，再解压更新 ZIP，将其中的文件和文件夹上传到现有仓库根目录，保持路径。提交到 main，等待 Actions 成功后刷新原网址。无需更改 .github 或 Pages 设置，不要上传个人迁移 JSON。

如果上次已更新，本次功能文件为 app/page.tsx、app/globals.css、components/usage-guide.tsx 和新增 components/submission-portals.tsx，另更新 scripts/smoke.mjs 的检查。直接使用累计包可避免漏文件。

同一网址和浏览器、未清除存储的情况下继续读取原记录。总览不改变存储格式。
